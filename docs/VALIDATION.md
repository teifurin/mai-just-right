## 后续真实验证方法

在根目录 `.env` 或进程环境中配置 `MCD_MCP_TOKEN` 后运行下列脱敏验证命令：

```sh
npm run verify:live -- --evidence evidence/mcp-check.json
npm run verify:live -- --quote-input PRIVATE_QUOTE_REQUEST.json --evidence evidence/quote-check.json
```

命令只输出调用元数据及必要金额，候选标题改为通用编号，不输出账户查询原文。公开前仍须核对 `liveBusinessCallSucceeded`、同一门店与渠道、原需求覆盖范围、`totalPath` 指向完整应付总额以及金额单位。`mcp:check`、`mcp:call` 属于开发者原始结果查看器，其输出不要直接公开。
