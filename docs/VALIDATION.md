# 验证记录

核验日期：2026-10-20。环境：Windows、Node.js 24.16.0、pnpm 11.25.0、独立无头 Chrome。当前版本为经过有限范围验收的参赛原型，不能据此宣称没有缺陷或适用于所有门店。

- `node scripts/verify-project.mjs`：94 项测试及 TypeScript 通过。覆盖组合计算、200 组独立穷举对照、金额与分账守恒、自然语言识别、历史恢复、MCP 协议与错误处理、访问控制、有界真实流程、运行时 Schema，以及实际 `braces` 补丁。
- 生产构建与 lint 通过。必需参赛文件齐全，官方声明原文 SHA-256 为 `cd28101bcb29cc8fb24b372fe91ce6b42c4a1487a54e01f7ade0c8c6a84241b7`。
- Dots 交付的两次提交在 v1.0.1 基线上应用后，82 个源文件与交付包逐字节一致；其原有 93 项测试已独立重跑通过。
- 本次补充修复 Workers 不支持 `redirect: error` 而导致实际请求失败的问题。客户端改用 `manual` 并拒绝 3xx，新增安全回归，禁止向重定向目标转发账户凭据。

## 真实生产 Worker 网页流程

在仅绑定本机的生产 Worker 中，通过脚本加载账户环境与私有映射，实际连接官方 `https://mcp.mcd.cn`。没有拦截或伪造账户接口返回。

验证范围：一个明确门店、到店自取，麦辣鸡腿汉堡、中薯条、中杯可乐及一个三件套。先发现当前工具 Schema，再读取菜单和详情，逐项核对主商品编码、子项规格、数量与核价单位。单点可乐显式选择中杯，不使用默认小杯或把规格子项编码当作单点主商品。

| 网页场景 | 实际结果 |
| --- | --- |
| 汉堡 + 中薯 + 中杯可乐，严格按需 | 单点 ¥46.00；同规格三件套 ¥33.50；少付 ¥12.50，额外餐品 0 |
| 只要汉堡，禁止额外餐品 | 只核价单点 ¥22.50，没有偷偷加入套餐 |
| 只要汉堡，允许额外餐品 | 三件套 ¥33.50，多出中薯和可乐，仍保留更便宜的单点 |
| 预算 ¥1 | 明确预算不足，保留原需求，没有删餐品凑预算 |

桌面四个分支通过；真实结果在 390、360 像素下无横向溢出。另在 360×800、启用触摸的手机模拟浏览器中，完整执行选店、选餐品和核价。没有页面 JavaScript 错误，真实数据没有写入 localStorage。

脱敏证据：[桌面流程与响应式布局](evidence/pickup-browser-2026-10-20.json)、[手机触摸模拟](evidence/pickup-mobile-2026-10-20.json)。只包含状态、时间、内部餐品标识与必要金额，不包含 Token、账户标识、门店编码、地址、搜索词或原始账户响应。

## 旧核价记录的适用范围

早期 CLI 的三组核价及其复核 JSON 保留原金额和时间，但它们没有显式核对单点可乐的中杯选项，标题不能证明请求规格。相关文件已标记为历史记录，不再作为同规格比较或本次网页验收的依据。

本次使用菜单主商品加明确中杯选项重新核价，金额仍为 ¥46.00 与 ¥33.50；依据是新请求的实际规格核对与网页结果，而不是旧金额碰巧相同。

## 安全与发布边界

- `.env` 只由脚本加载，未显示其内容；Token 只进入授权的本机服务端进程，未放入浏览器、公共源码、公开图片或托管网站。
- 私有映射、账户原始响应、真实账户截图与调试交付 ZIP 不进入发布源。公开 README 截图来自没有账户令牌的演示环境。
- 真实调用仍受只读工具允许列表与所有者权限控制，没有领券、下单、支付或兑换积分。
- 依赖锁文件及 `braces` 防护补丁沿用 v1.0.1；本次没有把源码检查通过写成依赖审计零告警。剩余公告及适用范围见 [SECURITY.md](../SECURITY.md)。
- `scripts/check-public-source.mjs` 检查跟踪路径、凭证模式及可选的已知环境密钥；`scripts/prepare-release.mjs` 使用明确源文件清单并生成 SHA-256 清单。检查通过不等于数学意义上的“绝无隐私问题”。

## 尚未覆盖

- 任意城市、其他门店、整个实时菜单和所有账户条件。私有映射须按实际 Schema 与返回重新核对。
- 本次门店的适用券列表为空，有券名称映射、自动叠券和领券没有真实验收；当前版本也不自动应用账户券。
- 真实限流、令牌失效、会话重试等异常主要通过合成测试验证，没有主动制造线上限流。
- 物理手机、原生系统下载交互及不同浏览器完整矩阵。
- 托管站点的账户调用没有配置个人令牌；本机真实联调不能当作远程托管账户功能已上线。

## 复核方法

```sh
npm run verify
npm run build
npm run lint
node scripts/check-public-source.mjs
npm run verify:live -- --evidence evidence/mcp-check.json
```
